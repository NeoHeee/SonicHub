# SonicHub 制作路线

## v0.1.0 核心链路验证

- [x] Flutter 项目与品牌基础
- [x] Songloft 连接、健康检查和登录
- [x] MIoT 设备列表
- [x] 音频 URL 投送
- [x] 暂停、继续、停止与音量
- [x] CI 分析、测试和 APK 构建
- [ ] 在真实 Songloft 与音箱环境验收
- [x] 固定 Android 签名

## v0.2.0 基础可用版

- 首页、搜索、设备和设置
- Songloft 曲库与外部搜索
- 当前播放状态和队列
- 局域网/公网双地址
- WebSocket 状态订阅

## v0.3.0 Audiobookshelf

- 书库、搜索、章节和继续收听
- M4B 章节
- 进度读取与回传
- 带鉴权音频代理

## v0.4.0 Subsonic/Navidrome

- 艺术家、专辑、歌曲和歌单
- 收藏、随机播放和转码质量
- 多音源全局搜索

## v0.5.0 LXBridge

- 在线搜索与即时地址解析
- 请求音质、实际音质和禁止降级
- 多来源去重及失败切换

## v0.6.0 高级音箱控制

- 多设备与多房间分组
- 定时任务和节假日规则
- 快捷播放场景

## v0.6.1 本机播放

- [x] 设备页增加本机播放目标
- [x] 音乐、Audiobookshelf 和音频直链支持本机播放
- [x] 本机播放暂停、继续、停止和进度拖动
- [ ] 后台播放、锁屏控制和通知栏媒体控制
